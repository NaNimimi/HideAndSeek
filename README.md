# 🙈 Прятки

Прятки на настоящей карте города: Expo (React Native) + Яндекс Карты 3.0 + Firebase.

## 1. Ключ Яндекс Карт

1. https://developer.tech.yandex.ru → «Подключить API» → **JavaScript API и HTTP Геокодер**.
2. В настройках ключа, в поле **«Ограничение по HTTP Referer»**, впиши: `pryatki.app`
   (JS API 3.0 без этого поля не работает; карта в приложении открывается именно с этого адреса).
   Ограничение начинает действовать примерно через 15 минут.
3. Вставь ключ в `src/config.ts` → `YANDEX_MAPS_API_KEY`.

## 2. Firebase

1. https://console.firebase.google.com → «Создать проект».
2. **Build → Firestore Database → Create database** → регион `europe-west` → режим **production**.
3. Вкладка **Rules** → вставь содержимое `firestore.rules` → **Publish**.
4. **⚙️ Project settings → Your apps → `</>` (Web)** → зарегистрируй приложение.
5. Скопируй `firebaseConfig` в `src/config.ts` → `FIREBASE_CONFIG`.

## 3. Установить на телефон (APK, всё работает, в том числе с выключенным экраном)

```bash
npm install
npx eas-cli@latest login          # бесплатный аккаунт на expo.dev
npx eas-cli@latest build -p android --profile preview
```

Через 10–20 минут EAS пришлёт ссылку и QR-код на `.apk` — открой на телефоне и установи.
Скинь ту же ссылку друзьям.

> iPhone: нужна платная учётка Apple Developer (`--profile preview -p ios`).

## 4. Быстрая проверка в Expo Go (без фона)

```bash
npx expo start --go
```

Отсканируй QR в **Expo Go**. Всё работает, кроме фоновой геолокации: в Expo Go держи игру открытой.

## 5. Telegram Mini App (Android, iPhone, компьютер)

Та же игра в вебе, с теми же комнатами: игроки из APK и из Telegram играют вместе.

```bash
npx expo export -p web
npx eas-cli@latest deploy --prod      # → https://pryatki.expo.app
```

1. В ключе Яндекса добавь в «Ограничение по HTTP Referer» второй домен: `pryatki.expo.app`.
2. В Telegram: @BotFather → `/newbot` → придумай имя бота.
3. @BotFather → `/newapp` → выбери бота → название, описание, картинка 640×360 →
   URL: `https://pryatki.expo.app` → короткое имя, например `play`.
4. Ссылку вида `https://t.me/<бот>/play` вставь в `src/config.ts` → `TELEGRAM_APP_LINK`
   и задеплой ещё раз. Тогда «Поделиться кодом» шлёт ссылку, по которой друг сразу попадает в комнату.

В Telegram позиция передаётся, только пока игра открыта (фона у веб-приложений нет).

## Как играть

- **Создать игру** → появится код. Нажми на код на карте, чтобы отправить его друзьям.
- Хост нажимает на карту, и там будет центр зоны. Нажатие на игрока меняет его роль.
- Режимы **Быстрая / Классика / Марафон** или любые свои настройки.
- 🟣 Круг — текущая зона (всё снаружи затемнено), 🟠 пунктир — следующая.
- 🔴 Точки показывают, где игроки были N минут назад, 🟢 зелёные — свои (если включено).
- Вышел из зоны дольше, чем разрешено, — выбываешь. Нашли — жми **«Меня нашли»**.
- Время вышло, а кого-то не нашли — побеждают прячущиеся.

## Фон и уведомления

- В установленной версии игрок один раз разрешает геолокацию **«Всегда»** (кнопка в лобби).
  После этого позиция передаётся и с выключенным экраном, а в шторке висит «Прятки — идёт игра».
- Все события (охота началась, зона сужается, новые точки, финал) приходят уведомлениями, даже если приложение свёрнуто.
- Если вышел из зоны с выключенным экраном, придёт уведомление «Ты вне зоны!».

## Структура

```
src/app/index.tsx              — главный экран
src/app/rules.tsx              — правила
src/app/room/[code].tsx        — комната: лобби или игра
src/components/Lobby.tsx       — карта, игроки, режимы, настройки
src/components/Game.tsx        — HUD, таймеры, зона, точки, итоги
src/components/YandexMap.tsx   — Яндекс Карты 3.0 (тёмная тема) в WebView
src/components/ui.tsx          — кнопки, переключатели, карточки
src/lib/game.ts                — игровая логика (зоны, время, кто кого видит)
src/lib/tracker.ts             — фоновая геолокация + проверка зоны
src/lib/notify.ts              — уведомления о событиях игры
src/lib/rooms.ts               — Firebase
src/theme.ts                   — цвета и шрифты
```
